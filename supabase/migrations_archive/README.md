# 書庫（適用済み・もう流れない）

ここにあるのは **ベースラインを作る前に書いたマイグレーション**。
内容はすべて `supabase/migrations/` のベースライン1本に畳み込まれている。

Supabase CLI が見るのは `supabase/migrations/` だけなので、ここのファイルは
`db push` でも `db reset` でも**実行されない**。置いてあるのは記録のため。

## なぜ畳んだか

`migrations/` に並んでいたのは「ダッシュボードで手作業で作った DB」への**差分だけ**で、
テーブルを作る SQL がリポジトリのどこにも無かった。
そのため空の DB に向けて流し直すと、1本目の
`alter table public.comments ...` が「そんなテーブルは無い」で落ちる状態だった。

現在の DB の姿をまるごと吸い出して1本のベースラインにし、
差分たちはその中に含まれたのでここへ退避した。

## 読むとき

**ここの SQL をコピーして新しいマイグレーションにしないこと。**
ベースライン適用後の DB には、ここの変更はすでに全部入っている。

当時なぜその変更をしたか（設計の経緯）を知りたいときだけ開く。
各ファイルの先頭コメントにその理由が書いてある。
